# Restyle for Zulip

자체 호스팅한 Zulip에 테마를 입히는 크롬 확장입니다. 팝업에서 도메인을 등록하고 테마를 고르면, 등록한 도메인에만 스타일이 적용됩니다. 서버는 건드리지 않습니다.

Zulip Server 12.0 기준으로 만들었습니다.

## 설치 (개발자 모드)

1. 이 저장소를 내려받습니다.
2. 크롬에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 선택합니다.

크롬 123 이상이 필요합니다. Edge, Whale 같은 크로미움 기반 브라우저에서도 같은 방법으로 설치할 수 있습니다.

## 사용법

1. Zulip 탭에서 확장 아이콘을 누르고 **이 사이트에 적용**을 누릅니다. 주소를 직접 입력해도 됩니다.
   - `zulip.example.com`, `https://zulip.example.com/#narrow/...`, `10.0.0.5:9991` 모두 됩니다(포트는 무시).
   - `*.example.com`으로 등록하면 하위 도메인 전체에 적용됩니다.
2. 크롬이 해당 사이트 접근 권한을 물으면 허용합니다.
3. 테마와 옵션을 고릅니다. 열린 탭에 바로 반영됩니다.

도메인별로 테마를 따로 지정할 수 있고, 스위치로 잠깐 끌 수도 있습니다. 설정은 `chrome.storage.sync`에 저장돼서 같은 계정으로 로그인한 다른 PC의 크롬에도 따라갑니다.

## 테마

| 테마 | 설명 |
| --- | --- |
| 차분한 뉴트럴 | 회색조 사이드바와 흰 본문, 남색 포인트. Zulip의 라이트/다크 설정을 따라감 |
| 다크 프로 | Zulip 설정과 상관없이 항상 다크. 청록 포인트, 시간은 고정폭 글꼴 |
| 메신저 말풍선 | 메시지 본문을 말풍선으로 감싸고 아바타를 원형으로. 나를 멘션한 메시지는 테두리로 강조 |
| 읽기 집중 | 아바타를 숨기고 줄 간격을 넓힘. 녹색 포인트, 본문 폭을 좁게 시작 |
| 디스코드 | 항상 다크. 왼쪽 끝에 채널 폴더 레일, DM 목록에 아바타, 둥근 아바타와 상태 점, 계급별 이름 색 |
| 노션 | 연회색 사이드바와 흰 본문. 문장형 섹션 제목, 폴더 색 배지, 대화 위의 큰 제목, 얇은 선 아이콘 |

디스코드와 노션 테마는 Zulip 기본 아이콘(보기 목록, 채널 `#`, 자물쇠 등)을 각자의 선 아이콘으로 바꿉니다.

디스코드 테마의 계급별 이름 색은 이름 앞의 계급(이병, 일병, 상병, 병장, 부사관, 장교, 장성)을 읽어서 색을 정합니다. 팝업에서 끌 수 있습니다.

공통 옵션:

- **한글 글꼴**: 확장에 들어 있는 Pretendard(본문)와 JetBrains Mono(코드)를 씁니다. 외부 네트워크가 막힌 환경에서도 동작합니다.
- **화면 밀도**: 촘촘 / 기본 / 여유. 사이드바 줄 높이와 메시지 간격이 바뀝니다. 글자 크기는 Zulip 자체 설정(개인 설정 → 환경 설정)을 그대로 씁니다.
- **본문 폭**: 좁게로 두면 메시지 목록과 입력창이 820px 안에서 가운데 정렬됩니다.

## 동작 방식

- `background.js`: 등록된 도메인 목록으로 콘텐츠 스크립트를 동적으로 등록합니다(`chrome.scripting.registerContentScripts`). 도메인을 추가하면 이미 열린 탭에도 바로 주입합니다.
- `content.js`: 페이지 로딩 초기에 `<html>`에 `data-zr-theme`, `data-zr-font` 같은 속성만 붙입니다. 마지막 설정을 페이지의 localStorage에 캐시해서 새로고침할 때 기본 테마가 잠깐 보이는 걸 막습니다.
- `styles/restyle.css`: 모든 규칙이 위 속성 아래에 있습니다. Zulip 12는 색을 `light-dark()` CSS 변수로 정의하므로, 대부분은 그 변수를 테마 토큰으로 다시 연결하는 방식입니다.
- `enhance.js`: 디스코드와 노션 테마에서 CSS만으로 안 되는 부분을 DOM에 덧붙입니다. 디스코드 레일, DM 아바타, 계급 표시(`data-zr-rank`), 폴더 배지, 노션의 큰 제목이 여기서 나옵니다. Zulip이 사이드바를 다시 그려도 MutationObserver로 다시 붙이고, 테마를 바꾸거나 끄면 전부 걷어냅니다.
- `tools/build-icons.py`: 두 테마의 아이콘 SVG를 `restyle.css` 끝부분에 다시 생성합니다. 아이콘을 고친 뒤 `python3 tools/build-icons.py`를 실행하세요.

조사한 Zulip 12.0 구조(클래스명, 변수, 레이아웃 계산)는 [`docs/zulip/`](docs/zulip/README.md)에 정리해 두었습니다.

Zulip 업데이트로 클래스명이나 변수명이 바뀌면 일부 스타일이 빠질 수 있습니다. 변수 위주로 덮어써서 크게 깨지지는 않게 했습니다.

## 리디자인 제안서와의 관계

`Zulip 리디자인 제안` 9개 안 중에서 CSS만으로 되는 것은 테마로 넣었습니다.

- 넣음: A 차분한 뉴트럴, B 다크 프로(색과 글꼴), D 메신저 말풍선, E 정보량 조절(밀도, 본문 폭), I 밀도 설정(일부)
- 아직 안 넣음: C 미해결 토픽 보드, F 할 일 허브, G 개인 섹션 사이드바, H 토픽 하나씩 읽기, B의 토픽 필터와 단축키 패널, D의 내 메시지 오른쪽 정렬. 새 화면이나 데이터가 필요해서 Zulip API를 호출하는 스크립트가 있어야 합니다.
